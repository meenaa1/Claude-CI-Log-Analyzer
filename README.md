# 🤖 Claude CI Log Analyzer

An automated CI/CD workflow tool that analyzes test failure logs using Claude AI and generates structured root-cause analysis reports directly in GitHub Actions job summaries.

## 📌 Features

- **Automated Failure Analysis:** Parses failed test execution logs and stack traces.
- **Root Cause Analysis:** Identifies potential locator mismatches, timeout issues, and assertion failures.
- **Actionable Fix Suggestions:** Recommends code changes and selector updates to help developers resolve failures.
- **GitHub Actions Integration:** Publishes formatted Markdown reports directly to the GitHub Actions job summary.
- **Secure API Key Management:** Uses GitHub repository secrets to store the Anthropic API key.

## 🚀 How to Set Up and Run

### Prerequisites

1. A GitHub account and repository.
2. Python 3.x.
3. An Anthropic API key.
4. GitHub Actions enabled for your repository.

### Step 1: Add Your Anthropic API Key

1. Open your GitHub repository.
2. Navigate to **Settings → Secrets and variables → Actions**.
3. Click **New repository secret**.
4. Set the secret name to `ANTHROPIC_API_KEY`.
5. Paste your Anthropic API key as the value and save it.

**Security note:** Never hardcode your API key in your Python script or commit it to GitHub.

### Step 2: Configure the Workflow

Ensure your `.github/workflows/test-analyzer.yml` workflow:

- Runs when manually triggered using `workflow_dispatch`.
- Installs the required Python dependencies.
- Executes `scripts/analyze_logs.py`.
- Passes `ANTHROPIC_API_KEY` securely through environment variables.
- Writes the generated Markdown report to `$GITHUB_STEP_SUMMARY`.

### Step 3: Run the Workflow

1. Open the **Actions** tab in your GitHub repository.
2. Select **CI Log Analyzer Bot**.
3. Click **Run workflow**.
4. Wait for the workflow to complete.
5. Open the completed workflow run and view the job summary to see the analysis report.

## 📊 Sample Output Report

The following is an example of the report the analyzer could generate:

### 🚨 Test Failure Summary

The checkout test failed because Selenium could not locate the element with ID `pay-now-button` on the payment page.

### 🔍 Root Cause Analysis

A potential DOM locator mismatch was identified. The test script searched for `pay-now-button`, but the actual DOM contained `submit-pay-btn`.

### 💡 Suggested Action / Fix

Update the selector in `tests/test_checkout.py` to match the actual element ID:

```python
driver.find_element(By.ID, "submit-pay-btn").click()
```

**Note:** The example above illustrates an expected analysis result. Actual findings depend on the log contents and the response generated by Claude AI.
